ℹ️ Data and model notes

Day 1, Day 2, Day 4 and Day 9 use the bundled road-grid optimizer schedules. The execution epoch advances every simulated hour all the way to the last delivery; it does not stop when vehicle-update epochs end. Pickup completion, delivered orders, pending pickups and hourly execution checkpoints are shown live. Uploaded CSV pairs use a clearly labelled browser-side road-grid estimate (not IPGA/SA). Use Upload Orders CSV and Upload Vehicles CSV, or drag-and-drop both files, then run the pair.

Important: The roads shown are the original HTML's schematic grid roads, not a real-world road-network graph. This standalone page replays the bundled optimizer schedules offline; it does not run IPGA/SA in the browser. To run the optimizer again for a new CSV pair, use the companion Python simulator.
